# Themes

`vague/` is a copy of [vague.nvim](https://github.com/vague-theme/vague.nvim) (`73f8aaa`) with a light palette. It follows `background`, so it switches with the terminal.

Copy this directory to `~/.config/nvim/themes/`. `init.lua` loads it as a local plugin. Colors are in `vague/lua/vague/config/internal.lua`.
